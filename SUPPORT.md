# Getting help

CyberForge is maintained by [Abdurrahman Kutlu](https://rahmankutlu.com). Pick the channel that fits; it keeps answers fast and searchable.

| I want to…                                     | Go to                                                                                                                        |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Install or run it                              | [Getting started](docs/getting-started.md), then a [bug report](https://github.com/rahmankutlu/cyberforge/issues/new/choose) |
| Understand a lab, rule, story or the API       | The [documentation](docs), the playground and the [API contract](docs/api/openapi.json)                                      |
| Report a bug or request a feature              | [GitHub issues](https://github.com/rahmankutlu/cyberforge/issues/new/choose)                                                 |
| Fix a translation                              | A **Translation** issue, or see [Localization](docs/localization.md)                                                         |
| Report a security vulnerability                | [SECURITY.md](SECURITY.md): privately, never in a public issue                                                               |
| Ask about training, workshops or collaboration | [info@rahmankutlu.com](mailto:info@rahmankutlu.com) or [rahmankutlu.com](https://rahmankutlu.com)                            |

## What to include

The version (Settings page or `GET /api/v1/settings/runtime`), how you run it (Docker or from source), the steps to reproduce and what you expected. Never paste real credentials or customer data: CyberForge's content is synthetic, and your report should be too.

## Response times

This is a volunteer-maintained open-source project. Issues are read, and security reports are prioritised; there is no response-time guarantee. The [roadmap](ROADMAP.md) shows what is planned.
